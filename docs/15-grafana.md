# Grafana

## Purpose

Grafana is included as a visualization service for Prometheus data.

## Implementation

Compose publishes container port 3000 as host port 1044 and persists `/var/lib/grafana` in the named `grafana_data` volume. No Grafana configuration files are present in the repository.

Dashboard provisioning is not currently automated. No datasource, dashboard JSON, panel query, variable, or alert rule is committed. Therefore the project does not currently guarantee a ready-to-use dashboard.

## Configuration

Open `http://127.0.0.1:1044` from the host. Add a Prometheus datasource manually with URL:

```text
http://prometheus:9090
```

Use the service name and container port from Grafana. `http://localhost:9090` would point to the Grafana container itself, not the Prometheus container.

After the datasource is connected, choose Explore and query the metrics exposed by FastAPI. Exact metric names should be selected from the Prometheus metric browser because they are generated by `prometheus-fastapi-instrumentator`, not declared in this repository.

## Security

The repository does not configure a Grafana admin credential, reverse proxy, TLS, or user provisioning. Do not expose the published Grafana port publicly without setting credentials and adding network controls.
